## 📖 Sobre o Projeto

O **Cookin' Up** foi criado com o objetivo de ajudar usuários a encontrarem novas receitas de forma simples, rápida e intuitiva.  
A aplicação apresenta uma interface moderna e responsiva, proporcionando uma experiência agradável durante a navegação.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- Vue 3
- Vite
- JavaScript
- HTML5
- CSS3

⚙️ Instalação e Configuração
Clone o repositório
```
git clone https://github.com/seu-usuario/cookin-up.git
```
## Acesse a pasta do projeto
```
cd cookin-up
```
## Instale as dependências
~~~
npm install
~~~
## Executando o Projeto

Para iniciar o servidor de desenvolvimento:
~~~
npm run dev
~~~
Após iniciar, acesse no navegador:xhgxghmguyi
~~~
http://localhost:5173
~~~ 
## Build para Produção
   
Para gerar os arquivos de produção:
~~~
npm run build
~~~
